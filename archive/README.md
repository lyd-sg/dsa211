# Historical work (read-only archive)

This directory preserves earlier project exploration. Files moved here have **not** been edited, re-executed or updated to reflect the group's latest consensus.

- [`online-shoppers/`](online-shoppers/) — superseded short Online Shoppers report notebook and original two-page brief. They reflect earlier assumptions.

The historical selection scripts are **not the current project entry point**. If deliberately reproducing that old bake-off, work inside `archive/dataset-selection/` using its preserved `requirements.txt` and original script paths. Some old scripts may rely on network downloads or local caches.

Generated `.pyc` bytecode was dropped from this branch; it can be recreated by Python. All substantive notebooks, scripts, original dataset and historical result artifacts were retained with their original blob hashes.
