**Archive policy:** Relocation uses the original Git blobs for historical PRDs, notebooks and workflows. The original data, previous experiment scores and stored outputs are not recalculated or overwritten. Some preserved historical internal hyperlinks and notebook instructions refer to paths that existed when that version was current; prefer the new version index for navigating archived materials, and execute notebooks only with the original root-relative data dependencies explicitly verified.
